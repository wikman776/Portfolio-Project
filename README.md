# Portfolio Website

A personal portfolio website created using HTML, CSS and JavaScript.

The purpose of this project was to practice frontend web development while creating a place to showcase my software projects, games, artwork and more.

## Features

* Responsive design for desktop, tablet and mobile devices
* Fixed navigation sidebar
* Project showcase pages
* Art gallery with fullscreen image viewer
* Blog / thoughts section
* Contact page with social links
* Custom styling using CSS Grid and Flexbox

## Pages

### Home

Introduction page containing a short presentation and profile image.

### Games

Showcases my released games and some handpicked learning projects.

### Software

Contains some of my software development projects 

### Art

Gallery of artwork I've made. 
Includes a JavaScript powered fullscreen image viewer.

Also som handpicked art learning projects I've taken.

### Thoughts

Simple blog section used for longer articles and posting my thoughts.

### Contact

Contains links to my:

* GitHub
* LinkedIn
* Bluesky
* Email

## Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Grid
* Flexbox
