What I learned

  • How to create a full Unity project from scratch, with a main menu, game over screen, options menu, etc.
  • How to write clean C# code and how to organize it well.
  • How to use Universal render pipeline, Shader graph, and how to make particle effects to make a visually appealing game.
  • How to add sound effects and background music to a game.

Type: Learning Project

Engine: Unity

Language: C#

Key Features:Shader graph, Universal render pipeline, scriptable objects, cinemachine camera controlls, minimap, day night cycle, particle effects

About

This is a Udemy course by Code Monkey that I took when I was starting out as a game developer and trying to learn all the basics of Unity, C#, and game development in general.

I am a big fan of Code Monkey and his courses, especially the way he writes code was very helpful to learn from when starting off my game dev career. And this course in particular I chose because it was for a strategy-ish type of game, which is the same genre my own future game would be set in.
