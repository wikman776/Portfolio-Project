What I learned

  • Developed a modular 3D city builder using state machines and the State Pattern.
  • Built flexible gameplay systems using Scriptable Objects and the Factory Pattern.
  • Created a modular input system using delegates and event-driven programming.
  • Implemented building placement, zoning and a simple economy system.
  • Connected gameplay data to a dynamic user interface.

Type: Learning Project

Engine: Unity

Language: C#

Key Features: City Builder, State Pattern, Scriptable Objects, Factory Pattern, UI

About

This is a city builder game I made as a learning project following along a Udemy course by Sunny Valley studios. The game is a simple prototype where you can place buildings, has a basic economy system, and also a procedural map generation system.

This is another course that I took while starting out as a game developer, and it was very helpfull for learning the basics of Unity. Sunny valley studio has a great emphasis on writing clean code, and to structure your project correctly, which is the main takeway from this projet for me.
