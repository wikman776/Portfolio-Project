What I learned

  • How to create a hexagonal grid in Unity
  • How to highlight tile ussing graph shader
  • How to implement basic character movement on a hex grid with different movement costs
  • How to Create a graphsearch algorithm in C#

Type: Learning Project

Engine: Unity

Language: C#

Key Features:Graphsearch, Hex Grid Movement

About

This is a small project I made following allong a youtube tutorial by sunny valley studios, in which you can move around a character on a hex grid.

The primary purpose of this project was to learn how to use the graphsearch alogrithm in a tile based game, which is the same design I ended up using in my own game Rogue Conflict.
