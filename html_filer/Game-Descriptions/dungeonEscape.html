Dungeon Escape

← Back to Games

What I learned

  • How to create a 2D platformer with fully working movement, controls and animations.
  • How to make phone ui and how to set up a game to work on android.
  • How to integrate Unity ads.
  • How to publish a game to the google play store.

Type: Learning Project

Engine: Unity

Language: C#

Key Features: 2D Platforming, Mobile Support, Tilemap Levels

About

Dungeon Escape is another learning project I made following along with the "The Ultimate Guide to Game Development with Unity" course on Udemy, just like the great Fleece.

The main reason for wanting to make this prototype was to learn the fundamentals of a 2D platformer game, since it is a genre I had very little previous experience doing game dev in, and I felt like I needed to fill in that knowledge gap.
